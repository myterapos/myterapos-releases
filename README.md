# MyteraPOS releases

Installers for the MyteraPOS till app for Windows.

## Install

1. Open [the latest release](https://github.com/myterapos/myterapos-releases/releases/latest).
2. Download `MyteraPOS-Setup-<version>.exe` under **Assets**.
3. Run it, then sign in with your shop code, username and password.

## Updates

Installed tills check here for new versions and update themselves. You don't need to download each new version.

## Help

Contact MyteraPOS support. This repository only holds the installers. The source code isn't published here.
